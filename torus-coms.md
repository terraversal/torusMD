# Torus Coms

These are keybinds (called coms) that will be used in Torus. C means the Ctrl key, and A means the Alt key.

## MODES

e -=- edit mode
/ -=- com mode

## COMS IN COMMAND MODE

j -=- move left
i -=- move up
l -=- move right
k -=- move down

C-i -=- move one block up
C-k -=- move one block down

p -=- add one line down of cursor
o -=- add one line above of cursor
u-j -=- add one space left of cursor
u-l -=- add one space right of cursor

c -=- change inside word


## COMS IN EDIT MODE

A-return -=- turns a selected equation into a result (2 * 2 when selected becomes 4). Only compatible with + - / and *
A-w -=- toggles word wrap
A-d -=- toggles auto-closing characters like " becoming "" or ( becoming ()
