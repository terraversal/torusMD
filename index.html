  • Type e for edit mode (while a file is open)
  • Type / (forward slash) for command mode
  • Type :escape and then hit enter while in command mode to escape the command line.
  • Type :help and then hit enter while in command mode to see a list of actions
  • Type :filenew and then hit enter while in command mode to create a file. Type your desired file name and path after you hit enter.
  • Type :fileopen and then hit enter while in command mode to open a file. Type your desired file path after you hit enter.
