          Type :escape and then hit enter while in com mode to escape
          the com line.

  • 
          Type e for edit mode (while a file is open) and you escaped
          the com line.
        
    • 
        
  • Type / (forward slash) for com mode.
    • 
        
  • 
          Type :help and then hit enter while in com mode to see a
          list of actions.
        
    • 
        
  • 
          Type :filenew and then hit enter while in com mode to
          create a file. Type your desired file name and path after you hit enter.
        
    • 
        
  • 
          Type :fileopen and then hit enter while in com mode to open
          a file. Select your desired file after you hit enter.
        
    • 
        
  • 
          Type :light, :dark, or
          :system and then hit enter to change appearance.
