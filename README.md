# TorusMD

Try a live demo here: https://terraversal.github.io/torusMD/

> **TorusMD is pseudo-operating system for productivity and markdown-previewing.**

## Features

- Homescreen with list of starting commands
- Error line that lives on the top of the screen
- Com line that stays on the bottom of the screen to run commands (coms)
